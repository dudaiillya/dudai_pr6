# Система управління навчальним процесом (Enum & TypeScript)

Цей репозиторій містить приклад використання `enum` та типізації в TypeScript для моделювання системи управління навчальним процесом університету. У файлі `src/index.ts` створено перелічення для статусів студентів, типів курсів, семестрів, оцінок і факультетів, визначені інтерфейси Student, Course і GradeRecord, а також реалізований клас UniversityManagementSystem з основними методами для реєстрації студентів, додавання курсів, виставлення оцінок, зміни статусу студентів, фільтрації та аналітики.

Проєкт включає:
- TypeScript код у каталозі `src`
- Скомпільований JavaScript у `dist`
- Конфігураційні файли tsconfig.json та package.json

Щоб зібрати проєкт локально:
1. Встановіть залежності: `npm install`
2. Запустіть компіляцію: `npm run build`
